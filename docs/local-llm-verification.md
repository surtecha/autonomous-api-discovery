# Local model discovery

`LLM_PROVIDER=ollama` selects a loopback-only Ollama chat-completions endpoint at `http://127.0.0.1:11434/v1`. The OpenAI SDK submits a JSON schema and validates the parsed index against the available candidate range. A literal dummy key is used for this endpoint; an exported hosted key is never forwarded to Ollama. `LLM_PROVIDER=openai` (the default) retains the hosted Responses API path.

The local runtime and downloaded models live in ignored `.runtime/ollama/`. Qwen2.5 7B uses Apache 2.0; the initially tested 3B variant uses a research license. Runtime/model provenance and the successful parsed probe are in `experiments/reports/local-model-20261115/`.

## Choose a provider

CLI flags override the corresponding environment setting. `--env-file .env` fills missing provider settings from the ignored private file; already exported variables take precedence over file values. Only `LLM_PROVIDER`, `LLM_MODEL`, and `OPENAI_API_KEY` are loaded. Secrets are never passed as command-line arguments.

```bash
# Local inference; no OpenAI key needed.
python -m scripts.discover --config experiments/configs/ecommerce.json \
  --output .runtime/local-run-new --strategy llm \
  --llm-provider ollama --llm-model qwen2.5:7b

# Hosted inference; OPENAI_API_KEY comes from the private file or environment.
python -m scripts.discover --config experiments/configs/ecommerce.json \
  --output .runtime/openai-run-new --strategy llm --env-file .env \
  --llm-provider openai --llm-model gpt-4.1-mini
```

Both commands require the matching authorized disposable target to be running. Provider validation is shared by CLI and graph discovery. Missing hosted credentials, missing model names, and unknown providers fail before discovery starts. Hosted mode uses the official OpenAI endpoint; local mode uses the fixed loopback endpoint and a dummy credential. A provider failure is reported in usage and falls back to gain within the existing budget; providers are not switched automatically.

This local configuration applies to the host CLI. Existing isolated Docker workers do not inherit the host's model server or private environment automatically; connecting those workers to a model server requires a separate explicit networking configuration.

## Run locally

Start the downloaded runtime from the project root:

```bash
OLLAMA_MODELS="$PWD/.runtime/ollama/models" OLLAMA_HOST=127.0.0.1:11434 \
  OLLAMA_NO_CLOUD=1 .runtime/ollama/ollama serve
```

Run a fresh-process comparison using the Python environment `api-discovery-ai`:

```bash
LLM_PROVIDER=ollama LLM_MODEL=qwen2.5:7b python -m scripts.benchmark \
  --output .runtime/local-comparison-new --repetitions 5 \
  --strategies fifo random gain llm
```

The output root must not already exist, to prevent accidental replacement of prior reports. Each trial starts a disposable target on an available port, uses the fixture policy (100 requests / 120 seconds), runs graph discovery, scores independent ground truth, and validates the generated SDK in restricted containers. Each repetition records its random seed (42–46 for five repetitions). Deterministic strategies are repeated controls, not independent stochastic samples. The model uses temperature zero; inference is not guaranteed bitwise reproducible across hardware or runtime versions.

The conservative token reservation permits three calls per session (2048 reserved per call, 8000 total), then uses gain fallback. Model usage reports actual input/output tokens, parsed selections, failure categories, latency, and unmeasured calls. A quota failure is distinct from a transient rate limit. Failed provider responses do not imply zero billed tokens or a verified provider bill.

## Evidence and limits

The hosted provider returned HTTP 429 with error type `insufficient_quota`. Fresh-process hosted runs are stored separately in `experiments/reports/llm-quota-20261115/`; these are fallback diagnostics, not successful LLM comparisons. Local model API fees are zero; hardware, electricity, and download costs were not metered. No inference about model quality beyond these fixtures and this small ranking budget is supported.

The full measured comparison is recorded in `experiments/reports/local-model-20261115/comparison.json` and summarized in `results.md` in that directory. Existing release reports were not regenerated by this workflow.
